# 官方網站動態設計

## 目標

讓 DesktopPetStudio 官方網站更有像素桌面寵物的陪伴感，同時保留產品、隱私與 OAuth 說明頁應有的可讀性與專業感。

## 動態層級

1. 首屏：目前選取語言的 Hero 文字短暫上移淡入，建立明確的進站節奏。
2. 內容：功能卡、步驟、圖片舞台、支援區塊與 FAQ 捲動進入可視範圍時依序淡入。
3. 像素角色：功能卡圖示以 2 至 4 像素為範圍上下呼吸；攀附小貓以微小角度擺動。互動時略微提升或縮放，但不改變版面尺寸。

## 可用性與限制

- 動畫僅使用 `transform` 與 `opacity`，降低重排與閃爍風險。
- JavaScript 無法載入時，內容預設可見。
- `prefers-reduced-motion: reduce` 時不進行進場、漂浮、擺動或按鈕位移。
- 法務與隱私頁只使用一次性的內容揭示，避免持續裝飾性動畫。
- 多語區塊切換後立即標記為可見，避免隱藏或切換動畫造成空白內容。

## 驗收

- 繁中、簡中、英文切換後只顯示所選語言，且內容不會因動畫停留在隱藏狀態。
- 每個 HTML 和 CSS 圖片引用均由 `scripts/validate_site.py` 驗證存在。
- 在減少動態偏好下，動畫樣式不會執行。
