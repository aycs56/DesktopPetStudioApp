# 創作者能力總覽設計

## 目標

將「自訂與工作坊」頁從純 JSON 參考入口，調整為一般玩家也能理解的創作能力總覽。頁面必須清楚說明已實作的自訂範圍，並把完整 JSON 欄位與 Markdown 文件保留給想深入的創作者。

## 受眾與成功標準

- 玩家能在首屏後理解：作品不只可換外觀，也能自訂動作、對話、日常養成與直播反應。
- 創作者能辨識三種可分享內容：單一姿勢、完整桌寵、養成玩法包。
- 所有敘述都可對應 `workshop-creator-json-guide.md` 的已支援資料欄位；不宣稱未完成功能。
- 繁中、簡中、英文內容等價；行動版維持單欄掃讀與可點擊的展開元件。
- 動畫使用既有可授權的專案像素素材，並遵循 `prefers-reduced-motion`。

## 資訊架構

1. 首屏：以玩家語言說明「從角色外觀到玩法規則都可分享」。
2. 三種作品：單一姿勢包、完整桌寵包、照顧玩法包。
3. 可自訂主題：角色與動畫、移動演出、氣泡與聲音、專注反應、Twitch Bits、AI 素材說明、多語系、商城/工作/事件/心情規則、安全打包。
4. 互動導覽：以 `details` 展開各主題的已支援項目；每個主題都附既有多幀像素動畫或 CSS 微動態。
5. 技術入口：保留原有 JSON 範例、欄位說明、下載 Markdown 與支援連結。

## 視覺與互動決策

- 使用青綠、珊瑚、奶油黃與墨藍沿用現有官方網站系統。
- 主題卡採等高、單層卡片與 7px 圓角；每張卡的像素圖以六幀 frame cycle 動畫展示。
- 展開說明使用原生 `details`，避免用額外腳本造成內容不可存取。
- 僅在非減少動態偏好下播放影格、輕微浮動、巡遊與氣泡呼吸效果；減少動態時保留靜態第一幀與所有文字。

## 範圍與非目標

- 本次僅改官方網站 `creator-json.html`、樣式、必要的揭示選取器與網站文件。
- 不修改桌面程式、工作坊 JSON schema、Steamworks 設定或公開宣稱任何 AI 代理功能。

## 驗證

- 以網站驗證腳本檢查內部連結、文件連結與必要 meta。
- 用 Chromium 在桌機與手機寬度檢查三種語言、展開內容與減少動態設定。
- 確認每個主題文字都只描述指南已有的姿勢、移動、Twitch、Prompt、養成與安全打包能力。
