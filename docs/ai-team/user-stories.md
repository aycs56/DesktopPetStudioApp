# 使用者故事

## EPIC: 了解產品

**Story: 多語系產品介紹**

作為一位潛在玩家，我想以繁體中文、簡體中文或英文瀏覽 Desktop Pet Studio 的核心功能，讓我能判斷它是否符合我的桌面陪伴與提醒需求。

**驗收重點**

- 首頁呈現姿勢工作台、提醒、照顧日常、AI 素材助手與工作坊相容內容。
- 切換語言後導覽、按鈕、主要內容與頁尾皆切換為相對應語言。
- 首頁不宣稱尚未實作的 Steamworks 功能。

## EPIC: 信任與 Google OAuth

**Story: 了解 Google Calendar 同步資料處理**

作為一位考慮登入 Google 的玩家，我想在登入前讀到日曆資料用途、讀取範圍、保存方式與停止同步方法，讓我能做出知情選擇。

**驗收重點**

- 隱私權政策清楚說明同步為選用功能、使用唯讀 Calendar scope、由預設瀏覽器完成登入。
- 隱私權政策說明權杖受 Windows DPAPI 保護並保留在使用者裝置上。
- 首頁與所有頁面皆可導向隱私權政策與使用條款。

## EPIC: 取得協助

**Story: 自助排除問題**

作為一位遇到同步或素材匯入問題的玩家，我想知道常見排除步驟與取得支援的管道，讓我能快速回到遊戲。

**驗收重點**

- 支援頁涵蓋桌寵顯示、姿勢素材、提醒、Google Calendar 同步與本機資料的常見處理方式。
- 發布前填入的支援信箱會在支援與隱私頁一致顯示。

## EPIC: 安全發佈

**Story: 避免以不完整資訊公開**

作為發佈者，我想在發佈 GitHub Pages 前自動檢查網域、GitHub 儲存庫與支援信箱設定，讓 OAuth 相關頁面不會帶著佔位資料上線。

**驗收重點**

- 一般程式碼檢查可在設定尚未填寫時執行。
- 正式 Pages 發佈流程會要求完成公開發佈設定。
