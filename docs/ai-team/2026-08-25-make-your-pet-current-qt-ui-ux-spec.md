# 製作專屬桌寵：現行 Qt 示意與文案 UI/UX 規格

## 使用路徑

1. 開啟 `make-your-pet.html` 並由上而下閱讀四步。
2. 每一步先看對應現行 Qt 畫面，再讀同側文字確認控制項名稱與完成結果。
3. 手機寬度維持既有文字在前、圖片在後的單欄順序。

## 元件決策

* **元件：** Image（僅替換既有的流程截圖，不新增媒體互動）。
* **Atlas 來源：** `https://huangchiyu.com/Vibe-UI-Atlas/components/image/`，2026-08-25。canonical demo 因本環境安全 URL 限制無法開啟，列為 QA 限制。
* **本機模式：** `data-and-media`；截圖是單一、可檢視的操作視覺，必須保有明確 `alt`、固定比例與窄螢幕完整呈現。
* **專案適配：** 保留既有 `<figure><img><figcaption>`、尺寸屬性與 `make-pet-screenshot`。截圖沒有點擊、載入、選取或錯誤狀態；缺檔由網站驗證阻擋發布。

## 文案規則

* 文字僅使用截圖可見的現行 Qt 控制項名稱，不提及舊版 Tk 工作台或不存在的網站功能。
* 圖說說明下一個可執行動作；完成提示說明玩家取得的結果與不會發生的自動覆寫。
* Hero、導覽、流程順序與視覺主題不在本次範圍內。
