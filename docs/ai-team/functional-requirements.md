# 條件式功能需求

## 公開網站

- 當訪客開啟根目錄時，系統必須顯示 Desktop Pet Studio 的產品介紹與導覽。
- 當訪客點選隱私權、條款或支援導覽時，系統必須開啟對應的獨立 URL 頁面。
- 當訪客使用語言選單切換繁體中文、簡體中文或英文時，系統必須切換目前頁面的文字，並在瀏覽器本機保留語言偏好。
- 當螢幕寬度較窄時，導覽必須可收合並保持所有頁面連結可達。
- 當使用者使用鍵盤操作時，所有導覽、語言選單與選單按鈕必須有可見焦點。

## Google OAuth 說明

- 當訪客閱讀隱私權政策時，系統必須說明 Google Calendar 同步為可選功能，並限於讀取行事曆事件以建立本機提醒。
- 當訪客閱讀隱私權政策時，系統必須說明 Google 授權於預設外部瀏覽器執行，而非嵌入式網頁視窗。
- 當訪客閱讀隱私權政策時，系統必須說明程式僅請求 `calendar.events.readonly`，OAuth 權杖以 Windows DPAPI 受保護並儲存於使用者裝置。
- 當訪客想停止同步或更換帳號時，系統必須提供在桌面程式內中斷 Google 連線並保留既有本機提醒的說明。

## 發佈

- 當 GitHub Actions 接到一般程式碼變更時，系統必須執行靜態網站檢查。
- 當發佈者手動執行 GitHub Pages 發佈工作流時，系統必須先檢查支援信箱、GitHub 儲存庫與自訂網域已設定，否則中止發佈。
- 當發佈設定完整時，系統必須將 `official-site` 目錄作為 GitHub Pages 成品上傳與部署。
