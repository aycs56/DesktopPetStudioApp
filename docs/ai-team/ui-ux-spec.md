# UI / UX 規格

## 視覺方向

- 以桌面陪伴、像素創作與溫暖工具感為主，而非傳統遊戲商城頁。
- 主色使用青綠、珊瑚紅、奶油黃與墨藍，維持清晰層級並避免單一色相主導。
- 首屏使用真實產品風格的像素貓點陣圖作為全幅背景，文字直接置於可讀性足夠的背景區域，不以浮動卡片包住主內容。
- 重複資訊可使用 8px 以下圓角的單層卡片；版面區段本身保持全寬、非卡片式。

## 資訊架構

1. 產品：用途、功能摘要、Google 同步簡介與支援入口。
2. 隱私權：資料分類、Google Calendar、保存 / 刪除、聯絡方式。
3. 使用條款：授權、使用者內容、第三方服務、免責與更新。
4. 支援：常見問題、問題回報所需資訊、支援聯絡方式。

## 互動

- 語言使用具文字標籤的原生選單，避免僅靠旗幟或縮寫造成理解負擔。
- 手機導覽以清楚的選單按鈕開關；展開後所有項目需足夠大的點擊區域。
- 支援頁的排除內容採可展開的 `details`，讓玩家快速掃描而不被長文淹沒。
- 動畫僅用於視覺重點與頁面進場；尊重 `prefers-reduced-motion`。
