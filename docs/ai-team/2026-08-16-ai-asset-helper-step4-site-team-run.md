# AI 素材助手四步教學網站更新 - Team Run

## 團隊設定

- Profile：Web
- Risk：Low
- Depth：Standard
- 決策者：產品需求已由使用者指定；PM 依現有主程式四步流程落實。

## Definition of Ready

- 已確認官方網站專案為 `DesktopPetStudioApp-site-publish`。
- 已確認主程式最新流程包含四個階段，第四步為「將素材匯入指定姿勢」。
- 已確認網站已有 `make-your-pet.html`、三語內容、兩張現有截圖與共用樣式。
- 不包含 GitHub Pages 發布、Steam 發布或主程式行為調整。

## 角色檢視

- PM：首頁入口必須直接降低從產品亮點到教學的跳轉成本。
- UI/UX：流程依閱讀方向排序；每一步的行動、結果與下一步要能在同一區塊理解。
- Lead Developer：重用網站既有多語系切換、截圖容器與 CSS 動態，不另引入依賴。
- QA：驗證四步完整性、首頁連結、三語內容、影像資源、桌機與手機顯示及靜態網站檢查。
- Technical Writer：文案只描述已完成的主程式功能，不承諾自動匯入或自動覆寫。

## Definition of Done

- 首頁可開啟「製作專屬桌寵」教學頁。
- 教學頁與現行主程式一致呈現四步流程與最新截圖。
- 三語內容、SEO 日期、網站驗證和視覺檢查完成。
