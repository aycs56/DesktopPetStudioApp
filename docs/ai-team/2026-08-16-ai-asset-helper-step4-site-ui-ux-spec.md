# AI 素材助手四步教學網站更新 - UI/UX 規格

## 流程與畫面

1. 首頁玩家區塊：在角色範例與三個準備步驟後方提供次要但清楚的教學按鈕。
2. 教學頁概覽：四張依序編號的流程卡，先讓玩家理解全貌。
3. 詳細步驟：每一步採文字與截圖成對布局；桌機使用左右交錯，行動版改為文字在上、圖片在下。
4. 完成區：重申步驟 4 的結果，提供前往自訂與工作坊或回首頁的下一步。

## 內容與控制

- 首頁 CTA 使用文字按鈕，不以圖示單獨承載主要意圖。
- 第 2 步說明將「複製 Prompt」與「複製 Prompt 並開啟網站」視為同一階段操作，不再描述為彈窗底部的獨立步驟。
- 第 4 步說明明確使用「編輯姿勢」按鈕名稱，並用醒目的完成提示說明不會自動覆寫素材。
- 截圖必須維持完整畫面比例；CSS 使用 `object-fit: contain`。

## 響應式與無障礙

- 桌機流程概覽為四欄；寬度不足時改為單欄，避免未滿列的空白與資訊遺漏。
- 所有 CTA 最小高度為 44px，行動版可依文字寬度延展。
- 截圖提供語義明確的替代文字；純裝飾動態圖保持 `aria-hidden`。
- 使用者偏好減少動態時，既有網站動態效果保持停用。
