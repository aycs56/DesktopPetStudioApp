# 實況模式官方網站介紹 - 功能需求

## FR-01：全站實況模式導覽

- 條件：玩家瀏覽任何官方網站頁面。
- 行為：主導覽與頁尾必須提供「實況模式」連結，導向 `streamer-mode.html`。
- 結果：繁中、簡中與英文會顯示相對應名稱；目前頁面使用 `aria-current="page"`。

## FR-02：首頁 Twitch 摘要

- 條件：玩家瀏覽首頁 Twitch 實況主模式區。
- 行為：區塊必須說明 Twitch Bits 可觸發姿勢、音效、專屬氣泡、持續時間及本機測試，並提供前往實況模式介紹頁的主要按鈕。
- 結果：創作者 JSON 指南保留為次要入口；內容不將未完成的平台或功能表述為已支援。

## FR-03：實況模式流程教學

- 條件：玩家進入 `streamer-mode.html`。
- 行為：頁面必須以順序呈現連接自己的 Twitch、建立 Bits 姿勢規則、設定觀眾氣泡、使用本機測試四個階段，並以可理解的視覺示意輔助閱讀。
- 結果：頁面需說明最低 Bits、最高 Bits 為 0 時沒有上限、持續時間為 1 至 60 秒、觸發結束後回到原動作，以及重疊規則取較精準範圍。

## FR-04：OBS 專用擷取說明

- 條件：玩家閱讀實況模式頁的 OBS 區。
- 行為：頁面必須說明啟用 OBS 擷取後，使用 OBS 的「視窗擷取」選擇 `Desktop Pet Studio - OBS Pet Capture`，並將來源置於遊戲畫面上方。
- 結果：必須說明預設為完整顯示器範圍、文字氣泡與提醒也會被擷取、切換顯示器會跟隨，以及「使用小畫布擷取」只是可選方案；不得把透明 Tk 視窗誤稱為遊戲擷取。

## FR-05：資料處理說明

- 條件：玩家閱讀 Twitch 連接或工作坊說明。
- 行為：頁面必須說明授權權杖以 Windows DPAPI 保護、只保存在當前 Windows 使用者本機、可中斷並刪除本機授權，且不包含在存檔或工作坊包中。
- 結果：不得聲稱 Desktop Pet Studio 伺服器會接收、儲存或轉送 Twitch 授權、觀眾資料、訊息或 Bits 事件。

## FR-06：行程提醒視覺

- 條件：玩家瀏覽首頁 Google Calendar 區。
- 行為：原本單一姿勢展示必須換成桌寵、提醒氣泡、行事曆與活動／工作／會議／紀念日標籤的動態場景。
- 結果：標籤與文字會隨目前網站語言切換；減少動態偏好下仍保持清楚可讀。

## FR-07：網站品質

- 條件：更新完成。
- 行為：新增頁面須列入網站地圖，三語內容、內部連結、SEO 基本資料、響應式畫面與 Console 都必須驗證。
- 結果：不覆寫既有未提交的 `make-your-pet.html` 變更，不發布到外部服務。
