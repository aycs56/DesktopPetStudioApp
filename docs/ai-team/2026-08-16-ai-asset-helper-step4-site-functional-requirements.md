# AI 素材助手四步教學網站更新 - 功能需求

## FR-01：首頁教學入口

- 條件：玩家瀏覽首頁「把角色帶進桌面」區塊。
- 行為：區塊必須顯示「製作專屬桌寵教學」按鈕，並導向 `make-your-pet.html`。
- 結果：按鈕在繁中、簡中與英文內容中皆有相對應文案；行動版按鈕維持可讀與可點擊尺寸。

## FR-02：四步流程

- 條件：玩家進入「製作專屬桌寵」頁面。
- 行為：概覽與詳細教學必須依序呈現步驟 1 至步驟 4。
- 結果：步驟名稱與程式現況一致：
  1. 準備角色或風格參考素材。
  2. 選擇 Prompt 模板、輸出語言與推薦 AI 網站，並在同一區塊複製 Prompt 或開啟網站。
  3. 檢查素材去背或裁切宮格圖片。
  4. 點選「編輯姿勢」，進入目前 Prompt 對應的姿勢編輯器，手動加入 PNG 或 GIF 並保存。

## FR-03：截圖與說明

- 條件：每一個教學步驟被顯示。
- 行為：每個步驟必須有對應的主程式截圖或等值的清楚示意，並含可理解的圖說。
- 結果：步驟 2 至步驟 4 使用目前四步流程的主程式畫面；截圖以響應式圖片呈現，不裁切重要按鈕或文字。

## FR-04：安全說明

- 條件：玩家閱讀步驟 4。
- 行為：文案必須說明「編輯姿勢」不會自動寫入、匯入或覆寫素材。
- 結果：玩家明確知道需在姿勢工作台自行加入檔案、確認播放順序並保存。

## FR-05：網站品質

- 條件：更新完成。
- 行為：新增影像必須存在、內部連結有效、三語內容可切換、網站驗證腳本通過。
- 結果：更新 `sitemap.xml` 的教學頁日期，且不加入私密資料或外部追蹤以外的新服務。
