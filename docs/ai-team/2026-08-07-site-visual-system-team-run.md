# 官方網站視覺與資訊頁體驗更新

日期：2026-08-07

Profile：Web + Docs

Risk：Medium（公開資訊頁、多語系與已公開的隱私／條款內容）
Depth：Standard

## 目標與範圍

改善 DesktopPetStudio 官方網站的全站視覺一致性與閱讀體驗。首頁的桌機與手機版需維持相同的內容階層；隱私權政策、使用條款與支援資訊需要具備有助理解的靜態／低干擾動畫插圖，但不得改寫法律或資料處理承諾。

不在本次範圍：修改隱私權政策或使用條款的實質法律內容、增加追蹤工具、蒐集新資料、改動 Google OAuth 流程。

## Role Council

- **CEO**：正式資訊頁採可信、安定、可閱讀的視覺語氣；動畫服務理解，不以裝飾取代內容。
- **PM**：首頁與資訊頁都要讓玩家在第一屏辨識目前頁面的目的，並能快速前往相關說明。
- **UI/UX**：同一個主題在桌機與手機使用相同閱讀順序；手機只改欄位排列與尺寸，不改資訊主從。照顧玩法示意保留「工作／商城／事件」的固定分類標籤，並確保不遮擋角色動畫。
- **Lead Developer**：保留既有三語架構與共用 JS，使用語意 HTML 和共用 CSS 元件，避免複製三套行為。
- **QA / Accessibility**：所有動態效果遵守 `prefers-reduced-motion`；插圖為輔助，文字內容仍可單獨閱讀；行動版操作目標至少 44px。
- **Technical Writer**：三語文案以直白的「資料留在本機、同步可選、可隨時中斷」等已實作事實呈現，不產生超出政策的承諾。

## User Stories

1. 作為首次到訪的玩家，我想在桌機或手機都看見相同的首頁內容架構，以便不必重新理解頁面。
2. 作為閱讀隱私權或條款的玩家，我想先掌握幾個重要重點，再閱讀完整內容，以便快速確認是否符合我的期待。
3. 作為需要協助的玩家，我想在支援頁清楚區分回報準備事項與常見問題，以便有效排查。

## Condition & Behavior Requirements

### 首頁照顧玩法示範

* **條件**：使用者在任何螢幕尺寸閱讀首頁照顧玩法區塊。
  * **行為**：內容說明、三個重點、主要按鈕和角色動畫維持同一張完整卡片的閱讀脈絡；小螢幕依序顯示文字再顯示動畫。
  * **行為**：角色動畫周圍保留「工作／商城／事件」固定標籤，標籤位置在桌機與手機一致，不遮擋角色或主要文字。

### 資訊頁插圖與摘要

* **條件**：使用者開啟隱私權、使用條款或支援資訊頁。
  * **行為**：頁首提供與該頁主題對應的像素角色插圖與低幅度動畫，並保留可獨立閱讀的標題與導言。
  * **行為**：隱私權與條款在完整內文前顯示三個短摘要與頁內錨點；摘要不得替代正式內文。
  * **行為**：螢幕寬度不足時，摘要依序換成單欄，插圖保持可見但不壓縮文字。

### 動態與可及性

* **條件**：使用者系統偏好減少動態。
  * **行為**：新增的浮動、呼吸和切換動畫停止或縮減；版面與所有資訊仍完整可用。

## UI / UX Spec

- 共用資訊頁英雄區：左側標題與導言、右側單一情境插圖；在窄螢幕垂直排列，文字永遠優先。
- 摘要卡：一列三張，使用不同但低飽和的色條區分類型，卡片本身是頁內錨點連結，不需要額外表單或彈窗。
- 法律頁側欄：桌機維持固定定位；手機置於正文之前並顯示為易掃描的橫向連結群組。
- 首頁照顧玩法：沿用米黃色卡、珊瑚色頂邊、角色動態和清楚的主要行動；工作／商城／事件標籤保留在同一個舞台中。手機保留卡片外框、內距和同一個視覺容器。
