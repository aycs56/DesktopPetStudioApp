  • 多句隨機氣泡與出現間隔
  • 右鍵呼叫姿勢的 WAV 音效
  • 建議快捷鍵與預設啟用狀態
專注模式與按鍵反應專注時，讓桌寵停在你指定的位置。

  • 固定位置，不觸發走動、攀附或下墜
  • 按鍵時重新播放專注動畫
  • 可自訂毫秒數前後文字，不記錄按鍵內容
Twitch 實況反應依 Bits、訂閱或贈送訂閱觸發指定姿勢。

  • 金額區間與播放持續時間
  • 專屬動畫、音效與文字氣泡

AI 素材提示與多語系附上 Prompt，讓玩家製作更多角色動作。

工作、商城與日常事件設定角色的工作、商品與日常事件。

安全打包與分享把素材和設定整理好，其他玩家就能直接匯入。

桌寵、姿勢與養成包使用相對路徑與允許的 JSON 欄位。程式不會執行 JSON 程式碼，也不需要把私人帳號資訊分享出去。

  • 支援姿勢、完整桌寵與養成內容分開分享
  • 素材與 WAV 音效可一併打包

FOR PLAYERS

匯入與使用作品

  1. 選擇作品在 Steam 工作坊訂閱作品，或準備創作者分享的本機套件。
  2. 載入並預覽在程式中掃描工作坊內容或匯入本機套件，確認作品類型與素材。

Collection names, covers and previews

Import a complete package to keep its assets with the pet. Preview its appearance and actions, then confirm before switching your current pet.

  • Set a menu name separately from the character name.
  • Use one square 1:1 cover image; covers do not use the six-panel pose crop workflow.
  • Identical content is not added twice, and imports leave the original files unchanged.

DIY effects and triggers

The DIY tutorial includes HTML, CSS and JavaScript examples. Use them with PetFX package rules to create animations and set their triggers and follow positions.

  • Place anchors manually on a pose or frame for effects to follow. The app does not automatically detect heads, hands or other body parts.
  • Selection, preview and enablement are separate. Selecting a card does not play it, and previewing does not enable it.
  • Choose effects, post-event poses and output targets for Twitch Bits, follows, subscriptions and gifts. Follows require the relevant authorization.

Character and animationAny character you have rights to use can become a desktop pet.

Add multiple transparent PNG frames or a GIF, adjust playback speed, and give an original character, rabbit, robot, or another design its own movement.

  • Multi-frame animation and relative asset paths
  • Playback from 0.25x to 4x
  • Right-facing walk art mirrors automatically when moving left
Movement and action stagingMake a character walk, hop, patrol, drift, or perform a signature sequence.

Use safe JSON values for distance, speed, gravity, and looping. Workshop content never needs to run executable code.

  • Wander, patrol, hop, shake, and drift
  • Multi-step sequences with easing curves
  • Choose whether gravity applies during a pose
Bubbles, sound, and hotkeysAdd dialogue, sound, and a hotkey to a pose.

Each pose can include random bubble text, a WAV sound, an enabled state, and a suggested hotkey. Players can adjust these settings.

  • Multiple random bubbles and intervals
  • WAV sound for right-click poses
  • Suggested hotkeys and default enabled state
Focus mode and key responseKeep your pet in a chosen spot while you focus.

A full pet pack can include a fixed focus pose. Players can drag the pet to a new position and optionally show key-response speed with custom text before and after the value.

  • Stay put without walking, clinging, or falling
  • Replay the focus animation on key input
  • Customize the millisecond bubble without recording keys
Twitch live reactionsTrigger a pose with Bits, subscriptions or gift subscriptions.

Set a Bits range, regular or gift subscription triggers, and a duration for a pose. Bubbles can include a viewer name, message, and Bits amount; the pet returns to its earlier action afterward.

  • Amount ranges and playback duration
  • Dedicated animation, sound, and bubbles
  • No Twitch account or authorization data is packaged
AI asset prompts and languagesInclude prompts to help players create more character actions.

Add AI Asset Helper prompts so a player can create more poses from their own reference art. Prompts may include multiple languages.

  • Pose packs display directly; full pets group prompts
  • Traditional Chinese, Simplified Chinese, English, Japanese, and more
  • Ask for one 3×2 six-panel PNG; crop it into frames before import
Jobs, shop items, and daily eventsSet up jobs, shop items, and daily events for your character.

Creators can make character-specific jobs, items, and events that affect hunger, affinity, mood, and in-game coins, and set rules for when they refresh.

  • Food, gifts, collectibles, and limited stock
  • Job duration, rewards, costs, and mood risk
  • Daily dialogue triggered by hunger, affinity, and mood
Safe packaging and sharingOrganize assets and settings so other players can import them directly.

Pet, pose and care packs use relative paths and allow-listed JSON data. The app never runs JSON as code, and private account information stays out of a shared pack.

  • Share poses, full pets, and care content separately
  • Bundle art and WAV sound together
  • No Google or Twitch tokens, or private player settings

桌寵 JSON 有三種封裝方式；PetFX 特效使用另列的獨立格式：姿勢包使用 "type": "pose"，適合分享一個右鍵呼叫姿勢與它的素材；完整桌寵包使用 "type": "pet"，以 pet_config.json 帶入基礎姿勢、提醒、快捷鍵與其他設定；養成內容則使用 "type": "care"，提供商城物品、工作與日常事件。

進階欄位與打包參考

把入口 JSON 和所有圖片、音效放在同一個資料夾，方便整包分享。其他玩家匯入時，程式會從 JSON 所在位置解析相對路徑。

MyWavePose/
  desktop_pet_studio_workshop.json
  assets/
    frame_01.png
    frame_02.png
    frame_03.png
    frame_04.png
    frame_05.png
    frame_06.png
    wave.wav

請使用 assets/frame_01.png 這類相對路徑，不要填入 C:\Users\... 等本機絕對路徑。素材建議使用透明背景 PNG；走動影格請面向右方，桌寵在往左移動時會自動鏡像。

單一姿勢 manifest

以下範例能建立一個揮手姿勢：使用六張獨立影格、播放音效、隨機氣泡，並以小跳躍方式移動。

{
  "schema_version": 1,
  "id": "my-wave-pose",
  "title": "揮手打招呼",
  "type": "pose",
  "content_kind": "single_pose",
  "assets_mode": "bundled",
  "pose": {
    "name": "揮手打招呼",
    "category": "custom",
    "animation_paths": [
      "assets/frame_01.png", "assets/frame_02.png", "assets/frame_03.png",
      "assets/frame_04.png", "assets/frame_05.png", "assets/frame_06.png"
    ],
    "playback_speed": 1.25,
    "sound_path": "assets/wave.wav",
    "bubble_texts": ["嗨，我在這裡！", "今天也一起加油"],
    "bubble_interval_sec": 20,
    "enabled": true,
    "movement": {
      "enabled": true,
      "mode": "hop",
      "speed": 1.2,
      "distance_px": 160,
      "vertical_px": 36,
      "duration_sec": 2.4,
      "loop": false,
      "gravity": false
    }
  }
}

移動參數補充

movement 只接受白名單資料，JSON 不會執行任意程式碼。可用模式為 none、wander、patrol、hop、shake、drift 與 sequence。其中 sequence 可用多段 dx、dy、duration_ms 與 easing 組成演出。

playback_speed

動畫倍率，支援 0.25 到 4.0；多數姿勢建議 0.75 到 1.5。

distance_px

水平距離或抖動幅度，範圍 0 到 2400。

vertical_px

垂直距離或跳躍高度；負數可用於向上漂移。

gravity

設為 false 時，姿勢期間不會進入自然下墜流程。

Twitch 直播欄位補充

可在任一姿勢內加入 twitch_trigger，依觀眾 Bits 金額、一般訂閱或贈送訂閱播放對應動畫、音效與氣泡。訂閱事件需要玩家授予相應 Twitch 權限。工作坊會分享這組玩法規則，但不會包含 Twitch 帳號、授權碼或權杖；每位玩家都必須連接自己的 Twitch。

"twitch_trigger": {
  "enabled": true,
  "subscription_enabled": true,
  "gift_subscription_enabled": true,
  "duration_sec": 8,
  "min_bits": 100,
  "max_bits": 499,
  "bubble_texts": ["謝謝 {viewer_name} 的 {amount} {currency}！"]
}

AI 素材提示欄位補充

ai_asset_prompts 至少提供一個語系。姿勢包直接顯示提示，完整桌寵包以標題分組。請 AI 先輸出一張 3×2 六宮格 PNG，再用「宮格圖片裁切」拆成六張影格，最後加入 animation_paths；不要直接把整張宮格當作單一影格。

"ai_asset_prompts": [
  {
    "id": "wave_ai_prompt",
    "name": "揮手姿勢",
    "pose_id": "wave",
    "zh": "使用我的角色參考圖製作揮手動畫，保留原有特徵與配件。輸出 1 張 3 x 2 六宮格透明 PNG，不拆成獨立檔案；每格 256 x 256 px，角色大小、中心點與底部定位一致，格間正好 5px。只在外側留白放 #0CB8EC 細虛線與 90 度直角裁切標記，不壓到角色；不要文字、格號或浮水印。"
  }
]

v1.3.0：桌寵收藏、名稱與封面

完整桌寵包的 title 是收藏與工作坊選單名稱，不會改寫 pet_config.json 的 pet_name。可用 cover_path 指定包內封面；沒有有效封面時顯示占位圖，舊包仍可使用。

{
  "schema_version": 1,
  "id": "my-complete-pet",
  "title": "小露娜桌寵",
  "type": "pet",
  "content_kind": "full_pet",
  "config_path": "pet_config.json",
  "cover_path": "cover.png",
  "assets_mode": "bundled"
}

匯入收藏會複製設定、封面與必要素材，保留原始檔案；先預覽，確認使用後才替換目前桌寵。同內容不重複收藏。跨電腦使用前，請先退出程式並在 Steam 確認同步完成。

DIY 網頁特效與工作坊分享

PetFX 是獨立的特效套件，使用 petfx.json 的 displayName 與 cover，不可替換成桌寵包的 title／cover_path。套件包含網頁程式與素材；封面用 1:1 單張圖片，不走姿勢六宮格裁切流程。完整範例、事件綁定與標點跟隨請參考程式內的 DIY 網頁特效教學。

  1. 選取作品，按「匯出特效…」並選擇存放位置。
  2. 匯出完成後，按「前往工作坊上傳」。
  3. 檢查內容資料夾、標題與封面，再確認發布。

匯出保留素材、封面、名稱、觸發規則與標點，不含登入資料、OBS 連線或個人啟停偏好；不覆寫原作品，也不會自動上傳。

分享前檢查

  • 每張影格的角色中心點盡量一致，避免播放時晃動。
  • 完整桌寵包以 config_path 指向 pet_config.json；不要包含 Google token、OAuth 設定、本機訂閱清單或其他私密資料。
  • 只放入你擁有或已取得授權的圖片、音效與文字；為素材來源與使用條件做清楚標記。
  • 先以工作坊頁的掃描與匯入流程在乾淨資料夾測試，再分享給其他玩家。

創作小提醒

Before you begin: choose one of three main sharing formats

Pet JSON content has three package formats; PetFX effects use the separate format described below. Use "type": "pose" for one right-click pose and its assets. Use "type": "pet" with pet_config.json for a complete pet configuration. Use "type": "care" for shop items, jobs, and everyday events.

Within these three formats, you can combine the eight topics below: character animation, movement, dialogue, focus, stream reactions, AI asset prompts, care rules, and safe packaging.

This guide covers 8 creation topics

  1. Character and animation
  2. Movement and action staging
  3. Bubbles, sound, and hotkeys
  4. Focus mode and key response
  5. Twitch live poses
  6. AI asset prompts and languages
  7. Jobs, shop items, and daily events
  8. Safe packaging and sharing

Advanced fields and packaging reference

Keep the entry JSON, images, and sound files in one folder. The app resolves relative paths from the JSON file, so a player can import that folder on another computer.

MyWavePose/
  desktop_pet_studio_workshop.json
  assets/
    frame_01.png ... frame_06.png
    wave.wav

Use a relative path such as assets/frame_01.png, never an absolute local path. Transparent PNG is recommended. Make walking frames face right; the app mirrors them automatically when moving left.

Single-pose manifest

Describe the content with schema_version, id, title, type, and pose. Place independent frames in pose.animation_paths, optionally assign a WAV through sound_path, and use bubble_texts for random dialogue.

{
  "schema_version": 1,
  "id": "my-wave-pose",
  "title": "Wave hello",
  "type": "pose",
  "content_kind": "single_pose",
  "assets_mode": "bundled",
  "pose": {
    "name": "Wave hello",
    "category": "custom",
    "animation_paths": ["assets/frame_01.png", "assets/frame_02.png", "assets/frame_03.png", "assets/frame_04.png", "assets/frame_05.png", "assets/frame_06.png"],
    "playback_speed": 1.25,
    "sound_path": "assets/wave.wav",
    "bubble_texts": ["Hi, I'm here!", "Let's do our best today."],
    "bubble_interval_sec": 20,
    "enabled": true
  }
}

Movement field reference

movement accepts only allow-listed data; JSON never executes arbitrary code. The available modes are none, wander, patrol, hop, shake, drift, and sequence. Tune an action with speed, distance_px, vertical_px, duration_sec, loop, and gravity.

Twitch live field reference

Add twitch_trigger to any pose to play its animation, sound, and bubble for Bits, regular subscriptions or gift subscriptions. Subscription events require the player's relevant Twitch permissions. Workshop packages share this gameplay rule, never a Twitch account, authorization code, or token; every player connects their own Twitch account.

"twitch_trigger": {
  "enabled": true,
  "subscription_enabled": true,
  "gift_subscription_enabled": true,
  "duration_sec": 8,
  "min_bits": 100,
  "max_bits": 499,
  "bubble_texts": ["Thanks {viewer_name} for {amount} {currency}!"]
}

AI asset-prompt field reference

Provide at least one language in ai_asset_prompts. Pose prompts appear directly; full-pet prompts are grouped by title. Generate one 3×2 six-panel PNG, use “Crop grid image” to split it into six frames, then add those frames to animation_paths. Do not import the whole grid as one frame.

"ai_asset_prompts": [
  {
    "id": "wave_ai_prompt",
    "name": "Wave pose",
    "pose_id": "wave",
    "en": "Create a waving animation from my character reference; preserve its features and accessories. Output one transparent 3 x 2 six-panel PNG, not separate files. Use 256 x 256 px panels, identical scale, centers and bottom anchors, and exactly 5px gaps. Place thin #0CB8EC dashed guides and sharp 90-degree crop marks only in outer margins, never over the character. No text, panel numbers or watermark."
  }
]

v1.3.0: pet collections, names and covers

A full-pet package uses title for its collection and Workshop menu name without changing pet_name in pet_config.json. Use cover_path for a cover inside the package. A missing or invalid cover shows a placeholder; older packages still work.

{
  "schema_version": 1,
  "id": "my-complete-pet",
  "title": "Luna pet",
  "type": "pet",
  "content_kind": "full_pet",
  "config_path": "pet_config.json",
  "cover_path": "cover.png",
  "assets_mode": "bundled"
}

Collection import copies settings, the cover and required assets while preserving the source files. Preview first; the current pet changes only after you confirm use. Identical content is not added twice. Before switching computers, exit the app and confirm that Steam has finished syncing.

DIY web effects and Workshop sharing

PetFX is a separate effect package format. It uses displayName and cover in petfx.json, not the pet-package fields title and cover_path. Packages contain web code and assets. Use one 1:1 cover image, not a pose grid. See the in-app DIY web effects tutorial for complete examples, event bindings and anchor following.

  1. Select your work, click “Export effect…” and choose a save location.
  2. After exporting, click “Go to Workshop upload”.
  3. Check the content folder, title and cover, then confirm publication.

Export preserves assets, the cover, name, trigger rules and anchors. It excludes login data, OBS connections and personal enabled preferences. It neither overwrites the original work nor uploads automatically.

Before you share

  • Keep the character center consistent across frames to prevent visual jitter.
  • For a full-pet pack, point config_path to pet_config.json; never include Google tokens, OAuth settings, or other private data.
  • Share only art, sound, and text you own or are licensed to distribute, then test importing from a clean folder.

Creator tip

Start a PNG animation with six images at about six frames per second. This makes it easier to adjust the animation and add more actions for the character.
