# 實況模式官方網站介紹 - User Stories

日期：2026-08-17
專案：Desktop Pet Studio Official Site
類型：靜態網站 UI／內容更新

## US-01：了解實況模式可做什麼

身為 Twitch 實況主，我想在官方網站找到獨立的實況模式介紹，讓我能在連接帳號前了解 Bits 如何觸發桌寵姿勢、音效與氣泡。

## US-02：依步驟完成設定

身為第一次設定直播互動的玩家，我想看到帳號連接、姿勢規則、觀眾氣泡與本機測試的明確順序，讓我不必猜測設定完成後該去哪裡繼續操作。

## US-03：安全地使用自己的 Twitch 帳號

身為重視帳號資料的實況主，我想知道授權、觀眾訊息與 Bits 事件只在我的電腦處理，且工作坊內容不會帶走我的授權資料。

## US-04：在 OBS 中只擷取桌寵

身為使用 OBS 的實況主，我想知道要使用哪個視窗擷取桌寵與文字氣泡，以及它會如何跟著顯示器範圍移動，讓設定視窗不會意外出現在直播畫面。

## US-05：看懂行程提醒情境

身為考慮使用行事曆同步的玩家，我想在首頁看到活動、工作、會議與紀念日等提醒示意，讓我快速理解桌寵提醒的是哪些日常情境。
