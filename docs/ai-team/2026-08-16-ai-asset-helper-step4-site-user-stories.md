# AI 素材助手四步教學網站更新 - User Stories

日期：2026-08-16  
專案：Desktop Pet Studio Official Site  
類型：靜態網站 UI／內容更新

## US-01：從首頁找到教學

身為想自訂角色的玩家，我想在首頁「把角色帶進桌面」區塊直接看到「製作專屬桌寵教學」按鈕，讓我不用猜測下一步該去哪裡完成素材製作。

## US-02：理解完整的四步流程

身為第一次使用 AI 素材助手的玩家，我想在教學頁看到與程式一致的四個步驟、真實畫面與簡短說明，讓我知道從準備參考素材、選擇 Prompt、檢查素材，到開啟對應姿勢匯入動畫的完整路徑。

## US-03：知道素材不會被自動覆寫

身為已有桌寵設定的玩家，我想知道「編輯姿勢」只會帶我前往對應編輯器，素材仍由我自行加入與保存，讓我能安心使用教學流程。

## US-04：跨語系閱讀相同流程

身為繁中、簡中或英文使用者，我想在切換網站語言後仍看到一致的四步流程與正確截圖說明，避免不同語言頁面提供互相矛盾的操作方式。
