# 創作者頁與首頁上市提示調整設計

## 目標

- 讓桌機版的「查看姿勢 JSON」與單張分享卡對齊，降低三卡區塊下方的視覺重量。
- 讓創作者能力卡在手機展開時不再讓收合按鈕、動畫與文字互相遮擋。
- 在首頁 Banner 直接傳達 Steam 上市日期，但不干擾主標、行動按鈕或固定小貓動畫。
- 讓支援頁標題在窄螢幕與桌機都有較易掃讀的斷行。

## 已確認設計

1. 桌機寬度大於 860px 時，「查看姿勢 JSON」行動按鈕寬度為三欄卡片群組的一欄，並與第一張卡片左側對齊；860px 以下維持單欄全寬。
2. 創作者能力卡關閉時只呈現標題、摘要與右側 `+`。展開時，摘要列下方以 2/3 文字、1/3 動畫的 Grid 呈現；`-` 圓鈕移到原動畫的右上位置，並保留清楚的區隔線。
3. Banner 右下加入半寬上市橫條。桌機保留右側定位，手機改為可讀的滿寬橫條並為固定小貓預留空間。文案隨網站語言切換。
4. 支援頁的三語主標於問句後斷行。

## 驗收條件

| 驗收項目 | 結果 |
| --- | --- |
| 1440px CTA 與單張分享卡同寬；390px CTA 與單張卡同寬 | pass |
| 390px 與 1440px 能力卡展開後，文字、插圖、分隔線及 `-` 不重疊 | pass |
| Banner 上市提示在桌機與手機完整可讀，且不壓住主行動按鈕 | pass |
| 支援頁三種語言均在指定位置換行 | pass |
