FOUR CLEAR STEPS

從登入到測試，直播前照著做就好

設定順序和主程式一致：先連接自己的帳號，再替三種 Twitch 事件建立姿勢規則、寫好觀眾氣泡，最後用完全本機的 Bits 測試確認效果。

  1. 01

    連接自己的 Twitch

    在「直播主模式」按下連接 Twitch。預設瀏覽器會開啟登入與授權頁；授權只保留在你目前使用的 Windows 帳號本機。

  2. 02
    BITS訂閱贈訂

    替姿勢設定直播觸發

    在姿勢工作台設定 Twitch Bits、一般訂閱或贈送訂閱觸發。Bits 可設定最低與最高金額；訂閱與贈送訂閱可在每個姿勢分別開啟，三者都能使用專用音效、氣泡與播放秒數。

  3. 03
    {viewer_name}{tier} / {amount}

    把支持內容帶進文字氣泡

    氣泡可帶入觀眾暱稱、留言、Bits 金額、訂閱層級、贈送數量、平台與事件類型。每一行可作為一則隨機顯示的專屬回應。

  4. 04

    先發送本機測試 Bits

    輸入測試暱稱、訊息和 Bits 後即可查看動畫、音效與氣泡。測試不會真的斗內、不需先連線，也不會保存測試事件。

FOUR CLEAR STEPS

从登录到测试，直播前照着做就好

设置顺序和主程序一致：先连接自己的账号，再为三种 Twitch 事件建立姿势规则、写好观众气泡，最后用完全本地的 Bits 测试确认效果。

  1. 01

    连接自己的 Twitch

    在“主播模式”按下连接 Twitch。默认浏览器会打开登录与授权页面；授权只保留在你目前使用的 Windows 账号本地。

  2. 02
    BITS订阅赠订

    为姿势设置直播触发

    在姿势工作台设置 Twitch Bits、普通订阅或赠送订阅触发。Bits 可设置最低与最高金额；订阅与赠送订阅可在每个姿势分别开启，三者都能使用专用音效、气泡与播放秒数。

  3. 03
    {viewer_name}{tier} / {amount}

    把支持内容带进文字气泡

    气泡可带入观众昵称、留言、Bits 数量、订阅等级、赠送数量、平台与事件类型。每一行可作为一则随机显示的专属回应。

  4. 04

    先发送本地测试 Bits

    输入测试昵称、消息和 Bits 后即可查看动画、音效与气泡。测试不会真的打赏、不需先连接，也不会保存测试事件。

FOUR CLEAR STEPS

From sign-in to testing, follow this before you go live

The order matches the app: connect your own account, create pose rules for all three Twitch events, write viewer bubbles, then confirm the result with a completely local Bits test.

  1. 01

    Connect your own Twitch

    Choose Connect Twitch in Streamer Mode. Your default browser opens the sign-in and consent page; the authorization stays local to your current Windows account.

  2. 02
    BITSSUBGIFT

    Give a pose a live-event rule

    Set Twitch Bits, subscription, or gift-subscription triggers in Pose Studio. Bits can use a minimum and maximum range; subscriptions and gifts can be enabled per pose. All three can use a dedicated sound, bubble, and playback time.

  3. 03
    {viewer_name}{tier} / {amount}

    Bring support details into the bubble

    Bubbles can include a viewer name, message, Bits amount, subscription tier, gifted-subscription count, platform, and event type. Each line can be one of the pose's random dedicated responses.

  4. 04

    Send a local test Bits event

    Enter a test viewer name, message, and Bits amount to preview animation, sound, and bubbles. It is not a real cheer, does not need a connection, and is not saved.

MAKE EVERY SUPPORT EVENT FEEL DELIBERATE

Bits、訂閱與贈送訂閱，都能換成清楚的角色演出

用姿勢規則安排三種支持事件的反應。觸發完成後，系統會自動回到觸發前的動作，不會把角色卡在直播姿勢。

  • Bits 用金額範圍選擇反應同一次 Bits 只會觸發一個姿勢。多個規則重疊時，範圍較精準的規則優先。
  • 訂閱與贈送訂閱可分別啟用在每個姿勢勾選要回應一般訂閱、贈送訂閱，兩者會使用同一姿勢的播放秒數與直播氣泡文字。
  • 讓支持資訊進入氣泡訂閱可帶入訂閱層級，贈送訂閱可帶入份數；所有事件都可帶入觀眾暱稱、平台與事件類型。

MAKE EVERY SUPPORT EVENT FEEL DELIBERATE

Bits、订阅与赠送订阅，都能换成清楚的角色演出

用姿势规则安排三种支持事件的反应。触发完成后，系统会自动回到触发前的动作，不会把角色卡在直播姿势。

  • Bits 用金额范围选择反应同一次 Bits 只会触发一个姿势。多个规则重叠时，范围更精确的规则优先。
  • 订阅与赠送订阅可分别开启在每个姿势勾选要回应普通订阅、赠送订阅，两者会使用同一姿势的播放秒数与直播气泡文字。
  • 让支持信息进入气泡订阅可带入订阅等级，赠送订阅可带入份数；所有事件都可带入观众昵称、平台与事件类型。

MAKE EVERY SUPPORT EVENT FEEL DELIBERATE

Bits, subscriptions, and gift subscriptions can all create a clear character moment

Use pose rules to stage reactions for all three support events. When a response ends, the app returns to the action that was playing before it, so a live pose never gets stuck.

  • Choose Bits reactions with amount rangesEach Bits cheer triggers only one pose. When rules overlap, the narrowest matching range wins.
  • Enable subscriptions and gifts independentlyChoose which poses react to subscriptions or gift subscriptions. Both use the live duration and bubble text configured for that pose.
  • Put support details in the bubbleSubscriptions can show a tier and gift subscriptions can show a count; every event can include the viewer name, platform, and event type.

OBS DEDICATED CAPTURE

讓 OBS 只抓桌寵與文字氣泡，不抓設定視窗

啟用「OBS 顯示器擷取舞台」後，DesktopPetStudio 會提供一個獨立的透明視窗給 OBS 擷取。它和你目前桌寵所在的顯示器同尺寸，因此桌寵可以在整個畫面活動。

  1. 在直播主模式啟用 OBS 擷取預設不勾選「使用小畫布擷取」，即可保留目前顯示器的完整範圍、桌寵位置、大小、走動與文字氣泡。
  2. 在 OBS 新增「視窗擷取」選擇 Desktop Pet Studio - OBS Pet Capture，放到遊戲畫面來源上方，再使用「符合螢幕」。
  3. 讓舞台隨顯示器切換桌寵移到另一台顯示器時，舞台會跟著切換。提醒、固定專注、Twitch Bits、訂閱、贈送訂閱與日常氣泡也會一起被擷取。

這是透明 Tk 視窗，請使用 OBS 的「視窗擷取」，不要使用「遊戲擷取」。只有需要舊式小範圍來源時，才啟用「使用小畫布擷取」。

OBS DEDICATED CAPTURE

让 OBS 只抓桌宠与文字气泡，不抓设置窗口

启用“OBS 显示器捕获舞台”后，DesktopPetStudio 会提供一个独立的透明窗口给 OBS 捕获。它和你目前桌宠所在的显示器同尺寸，因此桌宠可以在整个画面活动。

  1. 在主播模式启用 OBS 捕获默认不勾选“使用小画布捕获”，即可保留目前显示器的完整范围、桌宠位置、大小、走动与文字气泡。
  2. 在 OBS 新增“窗口捕获”选择 Desktop Pet Studio - OBS Pet Capture，放到游戏画面来源上方，再使用“适配屏幕”。
  3. 让舞台随显示器切换桌宠移到另一台显示器时，舞台会跟着切换。提醒、固定专注、Twitch Bits、订阅、赠送订阅与日常气泡也会一起被捕获。

这是透明 Tk 窗口，请使用 OBS 的“窗口捕获”，不要使用“游戏捕获”。只有需要旧式小范围来源时，才启用“使用小画布捕获”。

OBS DEDICATED CAPTURE

Capture only the pet and bubbles in OBS, never the settings window

Enable the OBS Monitor Capture Stage and DesktopPetStudio provides a separate transparent window for OBS. It matches the monitor where your pet currently lives, so the pet can move across the entire display.

  1. Enable OBS capture in Streamer ModeLeave Use small canvas capture unchecked to keep the full monitor area, current pet position, size, movement, and bubbles.
  2. Add Window Capture in OBSChoose Desktop Pet Studio - OBS Pet Capture, place it above your game source, then fit it to the screen.
  3. Let the stage follow the displayWhen the pet moves to another monitor, the stage follows. Reminders, Focus Mode, Twitch Bits, subscriptions, gift subscriptions, and daily bubbles are captured too.

This is a transparent Tk window: use OBS Window Capture, not Game Capture. Enable Use small canvas capture only when you specifically need the older compact source.

YOUR ACCOUNT, YOUR CONTROL

實況設定可分享，帳號資料不會被帶走

你可以把 Bits、訂閱與贈送訂閱規則放進工作坊姿勢 JSON，讓其他創作者使用自己的 Twitch 帳號啟用；你的授權與觀眾事件始終只在自己的電腦上處理。

授權只留在本機

Twitch 權杖由 Windows DPAPI 保護，僅存於目前 Windows 使用者的本機資料夾，不會被放進桌寵存檔或工作坊包。

隨時中斷並移除授權

在直播主模式選擇中斷，即可停止連線並刪除這台電腦上的授權檔；你的姿勢、提醒與桌寵存檔不會受影響。

{ }

創作者可分享規則，不分享私密資料

工作坊 JSON 可包含 Bits 範圍、訂閱和贈送訂閱開關、持續秒數與氣泡模板。下載作品的玩家必須連接自己的 Twitch，規則才會開始反應。

YOUR ACCOUNT, YOUR CONTROL

Share live rules, not account data

You can put Bits, subscription, and gift-subscription rules into Workshop pose JSON so other creators can enable them with their own Twitch account. Your authorization and viewer events always stay on your computer.

Authorization stays local

Twitch tokens are protected with Windows DPAPI in the current Windows user's local folder. They are never put into pet saves or Workshop packages.

Disconnect and remove it anytime

Disconnect in Streamer Mode to stop the connection and delete the local authorization file. Your poses, reminders, and pet save are unaffected.
