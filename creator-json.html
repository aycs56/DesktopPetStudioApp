Use JSON to create shareable desktop-pet content

This guide explains how to organize art, animation, movement, sound, bubbles, and AI asset prompts into workshop content that players can scan and import.

MAKE A PET YOUR OWN

不只是換造型，連角色的日常玩法也能一起創作

你可以從一個有趣的姿勢開始，也可以把角色、對話、移動、養成規則和實況互動整理成一份能讓其他玩家直接匯入的桌寵內容。

ONE NEW ACTION

單一姿勢包

替角色新增揮手、跳躍、驚訝或右鍵呼叫動作，連同影格、移動、氣泡、音效與快捷鍵一起分享。

A WHOLE COMPANION

完整桌寵包

把角色素材、基礎姿勢、提醒、專注模式和個人化設定組成一位完整的桌面陪伴者。

A DAILY GAMEPLAY LOOP

照顧玩法包

設計工作、商城、道具、日常事件與心情回應，讓每個角色都有不同的生活節奏。

WHAT CAN YOU CUSTOMIZE?

從一張角色圖，到一整套桌面互動

以下都是工作坊 JSON 已支援的內容。先挑一個最想做的主題開始，之後再慢慢把它變成你的角色世界。

角色與動畫任何有授權的角色，都能成為桌寵。

可放入多張透明 PNG 或 GIF 動畫，設定播放速度，讓原創角色、兔子、機器人或其他形象都有自己的動作。

  • 多幀動畫影格與相對素材路徑
  • 動畫速度 0.25x 到 4x
  • 走動素材面向右方，向左移動會自動鏡像
移動與動作演出讓角色走、跳、巡邏、漂浮，或演出一段專屬動作。

用安全的 JSON 參數設定移動距離、速度、重力與循環，不需要在工作坊內容裡執行程式。

  • 隨機走動、巡邏、跳躍、抖動、漂浮
  • 多段 sequence 與 easing 演出曲線
  • 可決定姿勢期間是否受到自然下墜影響
氣泡、音效與快捷鍵讓一個姿勢不只是播放圖片。

每個姿勢都能有隨機文字氣泡、WAV 音效、啟用狀態與建議快捷鍵，玩家仍能依自己的習慣調整。

  • 多句隨機氣泡與出現間隔
  • 右鍵呼叫姿勢的 WAV 音效
  • 建議快捷鍵與預設啟用狀態
專注模式與按鍵反應把角色留在喜歡的位置，陪伴一段專注時光。

完整桌寵可設計固定專注姿勢。玩家可拖曳重新擺位，並選擇以自己的文字顯示按鍵反應速度。

  • 固定位置，不觸發走動、攀附或下墜
  • 按鍵時重新播放專注動畫
  • 可自訂毫秒數前後文字，不記錄按鍵內容
Twitch Bits 實況反應觀眾支持可以變成角色的即時動作。

為姿勢設定 Bits 金額範圍與持續秒數，氣泡可帶入觀眾暱稱、留言和 Bits 數量；觸發後會回到原本動作。

  • 金額區間與播放持續時間
  • 專屬動畫、音效與文字氣泡
  • 不會打包任何 Twitch 帳號或授權資料
AI 素材提示與多語系把延伸角色動作的方法，也一起交給玩家。

可為作品提供 AI 素材助手 Prompt，玩家能依自己的角色圖延伸新姿勢；提示可提供多種語言版本。

  • 姿勢包直接顯示，完整桌寵可分組展開
  • 支援繁中、簡中、英文、日文與更多語系文案
  • 可明確引導六張獨立透明 PNG，而非六宮格
工作、商城與日常事件設計的不只是外觀，還可以是一整套相處方式。

創作者能做出角色專屬的工作、商品和事件，改變飽食度、親合度、心情與遊戲內金幣，並安排刷新規則。

  • 食物、禮物、收藏品與有限庫存
  • 工作時長、獎勵、消耗與心情風險
  • 依飽食度、親合度、心情觸發日常對話
安全打包與分享把素材和設定整理好，其他玩家就能直接匯入。

工作坊包使用相對路徑與白名單 JSON 資料。程式不會執行 JSON 程式碼，也不需要把私人帳號資訊分享出去。

  • 支援姿勢、完整桌寵與養成內容分開分享
  • 素材與 WAV 音效可一併打包
  • 不包含 Google、Twitch 權杖或玩家私密設定

WHAT CAN YOU CUSTOMIZE?

From one character image to a complete desktop interaction

Everything below is supported by Workshop JSON today. Choose the part you want to make first, then gradually turn it into your character's world.

Character and animationAny character you have rights to use can become a desktop pet.

Add multiple transparent PNG frames or a GIF, adjust playback speed, and give an original character, rabbit, robot, or another design its own movement.

  • Multi-frame animation and relative asset paths
  • Playback from 0.25x to 4x
  • Right-facing walk art mirrors automatically when moving left
Movement and action stagingMake a character walk, hop, patrol, drift, or perform a signature sequence.

Use safe JSON values for distance, speed, gravity, and looping. Workshop content never needs to run executable code.

  • Wander, patrol, hop, shake, and drift
  • Multi-step sequences with easing curves
  • Choose whether gravity applies during a pose
Bubbles, sound, and hotkeysMake a pose feel like more than a picture.

Every pose can have random bubble text, WAV sound, an enabled state, and a suggested hotkey that players may still change for themselves.

  • Multiple random bubbles and intervals
  • WAV sound for right-click poses
  • Suggested hotkeys and default enabled state
Focus mode and key responseKeep a character where it feels right during focused work or play.

A full pet can define a fixed focus pose. Players may drag it into place and optionally show their own key-response speed in custom wording.

  • Stay put without walking, clinging, or falling
  • Replay the focus animation on key input
  • Customize the millisecond bubble without recording keys
Twitch Bits reactionsViewer support can become an immediate character reaction.

Set a Bits range and duration for a pose. Bubbles can include a viewer name, message, and Bits amount; the pet returns to its earlier action afterward.

  • Amount ranges and playback duration
  • Dedicated animation, sound, and bubbles
  • No Twitch account or authorization data is packaged
AI asset prompts and languagesGive players a clear way to extend a character's actions.

Add AI Asset Helper prompts so a player can create more poses from their own reference art. Prompts may include multiple languages.

  • Pose packs display directly; full pets group prompts
  • Traditional Chinese, Simplified Chinese, English, Japanese, and more
  • Ask for six separate transparent PNGs, not a grid
Jobs, shop items, and daily eventsCreate not only an appearance, but a whole way to care for a character.

Creators can make character-specific jobs, items, and events that affect hunger, affinity, mood, and in-game coins, with refresh rules to balance them.

  • Food, gifts, collectibles, and limited stock
  • Job duration, rewards, costs, and mood risk
  • Daily dialogue triggered by hunger, affinity, and mood
Safe packaging and sharingOrganize assets and settings so other players can import them directly.

Workshop packs use relative paths and allow-listed JSON data. The app never runs JSON as code, and private account information stays out of a shared pack.

  • Share poses, full pets, and care content separately
  • Bundle art and WAV sound together
  • No Google or Twitch tokens, or private player settings

開始前：選擇三種主要分享方式

工作坊目前有三種主要封裝方式：姿勢包使用 "type": "pose"，適合分享一個右鍵呼叫姿勢與它的素材；完整桌寵包使用 "type": "pet"，以 pet_config.json 帶入基礎姿勢、提醒、快捷鍵與其他設定；養成內容則使用 "type": "care"，提供商城物品、工作與日常事件。

進階欄位與打包參考

讓入口 JSON 和所有圖片、音效留在同一個可攜資料夾內。其他玩家匯入時，程式會從 JSON 所在位置解析相對路徑。

MyWavePose/
  desktop_pet_studio_workshop.json
  assets/
    frame_01.png
    frame_02.png
    frame_03.png
    frame_04.png
    frame_05.png
    frame_06.png
    wave.wav

請使用 assets/frame_01.png 這類相對路徑，不要填入 C:\Users\... 等本機絕對路徑。素材建議使用透明背景 PNG；走動影格請面向右方，桌寵在往左移動時會自動鏡像。

單一姿勢 manifest

以下範例能建立一個揮手姿勢：使用六張獨立影格、播放音效、隨機氣泡，並以小跳躍方式移動。

{
  "schema_version": 1,
  "id": "my-wave-pose",
  "title": "揮手打招呼",
  "type": "pose",
  "content_kind": "single_pose",
  "assets_mode": "bundled",
  "pose": {
    "name": "揮手打招呼",
    "category": "custom",
    "animation_paths": [
      "assets/frame_01.png", "assets/frame_02.png", "assets/frame_03.png",
      "assets/frame_04.png", "assets/frame_05.png", "assets/frame_06.png"
    ],
    "playback_speed": 1.25,
    "sound_path": "assets/wave.wav",
    "bubble_texts": ["嗨，我在這裡！", "今天也一起加油"],
    "bubble_interval_sec": 20,
    "enabled": true,
    "movement": {
      "enabled": true,
      "mode": "hop",
      "speed": 1.2,
      "distance_px": 160,
      "vertical_px": 36,
      "duration_sec": 2.4,
      "loop": false,
      "gravity": false
    }
  }
}

移動參數補充

movement 只接受白名單資料，JSON 不會執行任意程式碼。可用模式為 none、wander、patrol、hop、shake、drift 與 sequence。其中 sequence 可用多段 dx、dy、duration_ms 與 easing 組成演出。

playback_speed

動畫倍率，支援 0.25 到 4.0；多數姿勢建議 0.75 到 1.5。

distance_px

水平距離或抖動幅度，範圍 0 到 2400。

vertical_px

垂直距離或跳躍高度；負數可用於向上漂移。

gravity

設為 false 時，姿勢期間不會進入自然下墜流程。

Twitch Bits 欄位補充

可在任一姿勢內加入 twitch_trigger，依觀眾 Bits 金額播放對應動畫、音效與氣泡。工作坊會分享這組玩法規則，但不會包含 Twitch 帳號、授權碼或權杖；每位玩家都必須連接自己的 Twitch。

"twitch_trigger": {
  "enabled": true,
  "min_bits": 100,
  "max_bits": 499,
  "bubble_texts": ["謝謝 {viewer_name} 的 {amount} {currency}！"]
}

AI 素材提示欄位補充

可選用 ai_asset_prompts，引導玩家延伸同一角色的姿勢。至少提供一個語系文案；介面會優先顯示目前語言，沒有時回退為中文或英文。單一姿勢包會直接顯示提示；完整桌寵包則以整包標題建立可展開群組。

"ai_asset_prompts": [{
  "id": "wave_ai_prompt",
  "name": "揮手姿勢 AI 說明",
  "pose_id": "wave",
  "zh": "請用我上傳的角色圖，製作揮手動畫。輸出 6 張獨立透明背景 PNG，檔名 frame_01.png 到 frame_06.png；不要六宮格、不要 sprite sheet、不要文字、不要浮水印。",
  "zh_cn": "请用我上传的角色图，制作挥手动画。输出 6 张独立透明背景 PNG；不要六宫格、不要 sprite sheet、不要文字、不要水印。",
  "en": "Use my character reference to create a waving animation. Output six separate transparent-background PNG frames; no grid, sprite sheet, text, or watermark."
}]

分享前檢查

  • 每張影格的角色中心點盡量一致，避免播放時晃動。
  • 完整桌寵包以 config_path 指向 pet_config.json；不要包含 Google token、OAuth 設定、本機訂閱清單或其他私密資料。
  • 只放入你擁有或已取得授權的圖片、音效與文字；為素材來源與使用條件做清楚標記。
  • 先以工作坊頁的掃描與匯入流程在乾淨資料夾測試，再分享給其他玩家。

創作小提醒

PNG 多幀動畫可先用 6 張圖片、每秒約 6 幀。這樣容易調整，也方便玩家替角色建立更多動作。

让入口 JSON 和所有图片、音效留在同一个可携资料夹内。其他玩家导入时，程序会从 JSON 所在位置解析相对路径。

MyWavePose/
  desktop_pet_studio_workshop.json
  assets/
    frame_01.png ... frame_06.png
    wave.wav

请使用 assets/frame_01.png 这类相对路径，不要填入本机绝对路径。素材建议使用透明背景 PNG；走动帧请面向右方，桌宠在往左移动时会自动镜像。

单一姿势 manifest

使用 schema_version、id、title、type 与 pose 描述内容。pose.animation_paths 放入六张独立帧，sound_path 可指定 WAV，bubble_texts 可设置随机气泡。

{
  "schema_version": 1,
  "id": "my-wave-pose",
  "title": "挥手打招呼",
  "type": "pose",
  "content_kind": "single_pose",
  "assets_mode": "bundled",
  "pose": {
    "name": "挥手打招呼",
    "category": "custom",
    "animation_paths": ["assets/frame_01.png", "assets/frame_02.png", "assets/frame_03.png", "assets/frame_04.png", "assets/frame_05.png", "assets/frame_06.png"],
    "playback_speed": 1.25,
    "sound_path": "assets/wave.wav",
    "bubble_texts": ["嗨，我在这里！", "今天也一起加油"],
    "bubble_interval_sec": 20,
    "enabled": true
  }
}

移动参数补充

movement 只接受白名单数据，JSON 不会执行任意代码。可用模式为 none、wander、patrol、hop、shake、drift 与 sequence。可用 speed、distance_px、vertical_px、duration_sec、loop 与 gravity 调整演出。

Twitch Bits 字段补充

可在任一姿势内加入 twitch_trigger，依观众 Bits 金额播放对应动画、音效与气泡。创意工坊会分享这组玩法规则，但不会包含 Twitch 账号、授权码或令牌；每位玩家都必须连接自己的 Twitch。

"twitch_trigger": {
  "enabled": true,
  "min_bits": 100,
  "max_bits": 499,
  "bubble_texts": ["谢谢 {viewer_name} 的 {amount} {currency}！"]
}

AI 素材提示字段补充

可选用 ai_asset_prompts，引导玩家延伸同一角色的姿势。至少提供一个语言文案；单一姿势包会直接显示，完整桌宠包会以整包标题建立可展开群组。提示请明确要求 6 张独立透明背景 PNG，并说明不要六宫格或 sprite sheet。

分享前检查

  • 每张帧的角色中心点尽量一致，避免播放时晃动。
  • 完整桌宠包以 config_path 指向 pet_config.json，不要包含 Google token、OAuth 设置或其他私密资料。
  • 只放入你拥有或已取得授权的图片、音效与文字，并先在干净资料夹测试导入。

创作小提醒

PNG 多帧动画可先用 6 张图片、每秒约 6 帧。这样容易调整，也方便玩家为角色建立更多动作。

Before you begin: choose one of three main sharing formats

Workshop content currently has three main package formats. Use "type": "pose" for one right-click pose and its assets. Use "type": "pet" with pet_config.json for a complete pet configuration. Use "type": "care" for shop items, jobs, and everyday events.

The three formats are not a limit on what you can create. You can combine the eight topics below: character animation, movement, dialogue, focus, stream reactions, AI asset prompts, care rules, and safe packaging.

This guide covers 8 creation topics

  1. Character and animation
  2. Movement and action staging
  3. Bubbles, sound, and hotkeys
  4. Focus mode and key response
  5. Twitch Bits streamer poses
  6. AI asset prompts and languages
  7. Jobs, shop items, and daily events
  8. Safe packaging and sharing

Advanced fields and packaging reference

Keep the entry JSON, images, and sound together. The app resolves relative paths from the JSON file, so a player can import the same folder on a different computer.

MyWavePose/
  desktop_pet_studio_workshop.json
  assets/
    frame_01.png ... frame_06.png
    wave.wav

Use a relative path such as assets/frame_01.png, never an absolute local path. Transparent PNG is recommended. Make walking frames face right; the app mirrors them automatically when moving left.

Single-pose manifest

Describe the content with schema_version, id, title, type, and pose. Place independent frames in pose.animation_paths, optionally assign a WAV through sound_path, and use bubble_texts for random dialogue.

{
  "schema_version": 1,
  "id": "my-wave-pose",
  "title": "Wave hello",
  "type": "pose",
  "content_kind": "single_pose",
  "assets_mode": "bundled",
  "pose": {
    "name": "Wave hello",
    "category": "custom",
    "animation_paths": ["assets/frame_01.png", "assets/frame_02.png", "assets/frame_03.png", "assets/frame_04.png", "assets/frame_05.png", "assets/frame_06.png"],
    "playback_speed": 1.25,
    "sound_path": "assets/wave.wav",
    "bubble_texts": ["Hi, I'm here!", "Let's do our best today."],
    "bubble_interval_sec": 20,
    "enabled": true
  }
}

Movement field reference

movement accepts only allow-listed data; JSON never executes arbitrary code. The available modes are none, wander, patrol, hop, shake, drift, and sequence. Tune an action with speed, distance_px, vertical_px, duration_sec, loop, and gravity.

Twitch Bits field reference

Add twitch_trigger to any pose to play its animation, sound, and bubble for a viewer's Bits amount. Workshop packages share this gameplay rule, never a Twitch account, authorization code, or token; every player connects their own Twitch account.

"twitch_trigger": {
  "enabled": true,
  "min_bits": 100,
  "max_bits": 499,
  "bubble_texts": ["Thanks {viewer_name} for {amount} {currency}!"]
}

AI asset-prompt field reference

Use optional ai_asset_prompts to show players how to extend a character. Provide at least one language. A pose pack is shown directly in the AI Asset Helper; a full-pet pack appears in an expandable group. Clearly ask for six separate transparent PNG frames, not a grid or sprite sheet.

Pre-share checklist

  • Keep the character center consistent across frames to prevent visual jitter.
  • For a full-pet pack, point config_path to pet_config.json; never include Google tokens, OAuth settings, or other private data.
  • Share only art, sound, and text you own or are licensed to distribute, then test importing from a clean folder.

Creator tip

Start a PNG animation with six images at about six frames per second. This is easy to adjust and gives players a clear base for making more character actions.
