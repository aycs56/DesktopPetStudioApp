CREATOR DOCUMENTATION

Use JSON to create shareable desktop-pet content

This guide explains how to organize art, animation, movement, sound, bubbles, and AI asset prompts into workshop content that players can scan and import.

開始前：選擇要分享的內容

姿勢包使用 "type": "pose"，適合分享一個右鍵呼叫姿勢與它的素材。完整桌寵包使用 "type": "pet"，以 pet_config.json 帶入基礎姿勢、提醒、快捷鍵與其他設定。養成內容則可使用 "type": "care"，提供商城物品、工作與日常事件。

1. 建立資料夾

讓入口 JSON 和所有圖片、音效留在同一個可攜資料夾內。其他玩家匯入時，程式會從 JSON 所在位置解析相對路徑。

MyWavePose/
  desktop_pet_studio_workshop.json
  assets/
    frame_01.png
    frame_02.png
    frame_03.png
    frame_04.png
    frame_05.png
    frame_06.png
    wave.wav

請使用 assets/frame_01.png 這類相對路徑，不要填入 C:\Users\... 等本機絕對路徑。素材建議使用透明背景 PNG；走動影格請面向右方，桌寵在往左移動時會自動鏡像。

2. 寫入單一姿勢 manifest

以下範例能建立一個揮手姿勢：使用六張獨立影格、播放音效、隨機氣泡，並以小跳躍方式移動。

{
  "schema_version": 1,
  "id": "my-wave-pose",
  "title": "揮手打招呼",
  "type": "pose",
  "content_kind": "single_pose",
  "assets_mode": "bundled",
  "pose": {
    "name": "揮手打招呼",
    "category": "custom",
    "animation_paths": [
      "assets/frame_01.png", "assets/frame_02.png", "assets/frame_03.png",
      "assets/frame_04.png", "assets/frame_05.png", "assets/frame_06.png"
    ],
    "playback_speed": 1.25,
    "sound_path": "assets/wave.wav",
    "bubble_texts": ["嗨，我在這裡！", "今天也一起加油"],
    "bubble_interval_sec": 20,
    "enabled": true,
    "movement": {
      "enabled": true,
      "mode": "hop",
      "speed": 1.2,
      "distance_px": 160,
      "vertical_px": 36,
      "duration_sec": 2.4,
      "loop": false,
      "gravity": false
    }
  }
}

3. 設計移動，而不是執行程式

movement 只接受白名單資料，JSON 不會執行任意程式碼。可用模式為 none、wander、patrol、hop、shake、drift 與 sequence。其中 sequence 可用多段 dx、dy、duration_ms 與 easing 組成演出。

playback_speed

動畫倍率，支援 0.25 到 4.0；多數姿勢建議 0.75 到 1.5。

distance_px

水平距離或抖動幅度，範圍 0 到 2400。

vertical_px

垂直距離或跳躍高度；負數可用於向上漂移。

gravity

設為 false 時，姿勢期間不會進入自然下墜流程。

4. 加入 Twitch Bits 直播姿勢規則

可在任一姿勢內加入 twitch_trigger，依觀眾 Bits 金額播放對應動畫、音效與氣泡。工作坊會分享這組玩法規則，但不會包含 Twitch 帳號、授權碼或權杖；每位玩家都必須連接自己的 Twitch。

"twitch_trigger": {
  "enabled": true,
  "min_bits": 100,
  "max_bits": 499,
  "bubble_texts": ["謝謝 {viewer_name} 的 {amount} {currency}！"]
}

5. 提供 AI 素材提示

可選用 ai_asset_prompts，引導玩家延伸同一角色的姿勢。至少提供一個語系文案；介面會優先顯示目前語言，沒有時回退為中文或英文。單一姿勢包會直接顯示提示；完整桌寵包則以整包標題建立可展開群組。

"ai_asset_prompts": [{
  "id": "wave_ai_prompt",
  "name": "揮手姿勢 AI 說明",
  "pose_id": "wave",
  "zh": "請用我上傳的角色圖，製作揮手動畫。輸出 6 張獨立透明背景 PNG，檔名 frame_01.png 到 frame_06.png；不要六宮格、不要 sprite sheet、不要文字、不要浮水印。",
  "zh_cn": "请用我上传的角色图，制作挥手动画。输出 6 张独立透明背景 PNG；不要六宫格、不要 sprite sheet、不要文字、不要水印。",
  "en": "Use my character reference to create a waving animation. Output six separate transparent-background PNG frames; no grid, sprite sheet, text, or watermark."
}]

分享前檢查

  • 每張影格的角色中心點盡量一致，避免播放時晃動。
  • 完整桌寵包以 config_path 指向 pet_config.json；不要包含 Google token、OAuth 設定、本機訂閱清單或其他私密資料。
  • 只放入你擁有或已取得授權的圖片、音效與文字；為素材來源與使用條件做清楚標記。
  • 先以工作坊頁的掃描與匯入流程在乾淨資料夾測試，再分享給其他玩家。

創作小提醒

PNG 多幀動畫可先用 6 張圖片、每秒約 6 幀。這樣容易調整，也方便玩家替角色建立更多動作。

Before you begin: choose what to share

Use "type": "pose" for one right-click pose and its assets. Use "type": "pet" with pet_config.json for a complete pet configuration. Use "type": "care" for shop items, jobs, and everyday events.

1. Build a portable folder

Keep the entry JSON, images, and sound together. The app resolves relative paths from the JSON file, so a player can import the same folder on a different computer.

MyWavePose/
  desktop_pet_studio_workshop.json
  assets/
    frame_01.png ... frame_06.png
    wave.wav

Use a relative path such as assets/frame_01.png, never an absolute local path. Transparent PNG is recommended. Make walking frames face right; the app mirrors them automatically when moving left.

2. Write a single-pose manifest

Describe the content with schema_version, id, title, type, and pose. Place independent frames in pose.animation_paths, optionally assign a WAV through sound_path, and use bubble_texts for random dialogue.

{
  "schema_version": 1,
  "id": "my-wave-pose",
  "title": "Wave hello",
  "type": "pose",
  "content_kind": "single_pose",
  "assets_mode": "bundled",
  "pose": {
    "name": "Wave hello",
    "category": "custom",
    "animation_paths": ["assets/frame_01.png", "assets/frame_02.png", "assets/frame_03.png", "assets/frame_04.png", "assets/frame_05.png", "assets/frame_06.png"],
    "playback_speed": 1.25,
    "sound_path": "assets/wave.wav",
    "bubble_texts": ["Hi, I'm here!", "Let's do our best today."],
    "bubble_interval_sec": 20,
    "enabled": true
  }
}

3. Design movement, not executable code

movement accepts only allow-listed data; JSON never executes arbitrary code. The available modes are none, wander, patrol, hop, shake, drift, and sequence. Tune an action with speed, distance_px, vertical_px, duration_sec, loop, and gravity.

4. Add a Twitch Bits streamer pose rule

Add twitch_trigger to any pose to play its animation, sound, and bubble for a viewer's Bits amount. Workshop packages share this gameplay rule, never a Twitch account, authorization code, or token; every player connects their own Twitch account.

"twitch_trigger": {
  "enabled": true,
  "min_bits": 100,
  "max_bits": 499,
  "bubble_texts": ["Thanks {viewer_name} for {amount} {currency}!"]
}

5. Add AI asset prompts

Use optional ai_asset_prompts to show players how to extend a character. Provide at least one language. A pose pack is shown directly in the AI Asset Helper; a full-pet pack appears in an expandable group. Clearly ask for six separate transparent PNG frames, not a grid or sprite sheet.

Pre-share checklist

  • Keep the character center consistent across frames to prevent visual jitter.
  • For a full-pet pack, point config_path to pet_config.json; never include Google tokens, OAuth settings, or other private data.
  • Share only art, sound, and text you own or are licensed to distribute, then test importing from a clean folder.

Creator tip

Start a PNG animation with six images at about six frames per second. This is easy to adjust and gives players a clear base for making more character actions.
